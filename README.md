# WIMP

年齢ごとの月額支出、給与等収入、年金収入、想定利回りを使って、月次の金融資産残高を試算する静的ウェブアプリです。外部ライブラリやサーバー側の処理は使いません。

## 起動

このディレクトリで次を実行し、`http://localhost:8000` を開きます。

```sh
python3 -m http.server 8000
```

静的ファイルを公開できるホスティングにも、そのまま配置できます。

## 公開

GitHub Actions は `main` への push 時に試算テストを実行し、成功した場合だけ GitHub Pages に公開します。`main` 向けのプルリクエストでも同じテストを実行します。公開対象は `index.html`、`styles.css`、`app.mjs`、`engine.mjs` です。

公開 URL: https://shinichi-takayanagi.github.io/wimp/

## 試算の前提

- 1か月ごとに、月初の金融資産に対する運用損益、給与等収入・年金収入、月額支出の順で計算します。
- 収入が月額支出を上回る場合は差額を金融資産に加え、不足する場合は金融資産から取り崩します。金融資産を使い切った後の不足分は別に集計します。
- 想定利回りとインフレ率は、それぞれ複利の月率に換算します。月額支出の切替は、設定した年齢になった月から適用します。
- 年金は指定した受給開始年齢から毎月定額で受け取るものとして計算します。実際の振込周期、税金、社会保険料、繰上げ・繰下げによる受給額の変更は計算しません。入力額には手取りの見込額を使ってください。
- 試算条件はブラウザ内に自動保存されます。月次データはCSV、グラフはPNGでダウンロードできます。
